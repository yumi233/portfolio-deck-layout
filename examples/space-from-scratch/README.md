# 示例：室内空间项目，从零新建

和 `nodes-bamboo-court`（产品 / 家具类，改造原稿）互为补充。这份示例是**室内 / 建筑类**，**没有原稿**，只有 6 张照片。

- **起步**：`K.blank_deck(base=现成的 16:9 pptx)` 作底稿，不用 python-pptx 自带的默认模板（Keynote 打开时会弹窗卡住）。
- **强调色**：`AS.suggest_accent(三张主图)`。这组照片得到砖木色 `#6F3A2A`，只用在分析页的圆点和提示卡片上。
- **页面**：A 封面 → B 目录 → C 扉页 → D 人流与视线（图 + 强调色时间点）→ G 单元标题（局部图作预告，不抠图）→ I 主图说明 → I′ 多视角（庭院 / 夜景）→ J 细节（轴测爆炸 + 3 处细部，都是 AI 占位框）→ K 情境（双图错落）→ M 大图 → 封底。
- **空间类和产品类的不同**：效果图直角原样放，不抠图、不加模糊；细节是材料节点和细部，不是物体的爆炸图特写。

照片不随技能附带。运行时把任意一个空间项目的 6 张照片按文件名放进一个文件夹即可。
