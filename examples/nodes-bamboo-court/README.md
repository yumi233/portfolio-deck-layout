# 示例：有节·竹院 茶家具设计报告

- **原稿**：42 页，1200×675pt，纸纹背景，墨绿配色，有页眉、页码、页脚，正文只有中文。
- **结果**：51 页，960×540pt，中英对照。
- **新增页**：04、05 两章的扉页，6 张单品标题页，封底。

文件：
- `build.py`：完整的构建脚本，用法 `python -I build.py SOURCE.pptx OUT.pptx WORKDIR`。
- `en_text.py`：全部英文对照，以及扉页标语、案例页的成对句。

这里面有哪些做法值得照搬：
- **配色**：原稿配色表 TEXT / LINE / FILL / ACCENTS 的写法，加上逐页覆盖（地图、定位图）。
- **调研章节判定**：用 `chapter(i)` 判断哪些章节可以用茶红。
- **时间轴（第 4 页）**：保留上下交错的排法，每条只配一句很短的英文（*Tea enters the written word.*）。
- **工艺路线（第 24 页）**：按每行文字的实际高度重排行距。
- **事后对齐**：`ANCHORS` 用来把编号、圆点、图注重新对齐。
- **单品页**：每件产品依次是 G（模糊预告）→ H（草图）→ I（抠图渲染）。
- **案例页**：图片在左，右侧是居中的成对文字栏。

这份脚本依赖原稿的形状名，**不能直接用在别的稿子上**。换一份稿子时，先用 `scripts/inventory.py` 读稿，再照这个结构写新的脚本。

## 第二轮：换新渲染、改名（`build_new_renders.py` + `regions.py`）
家具改了设计，用户发来 16 张灰底影棚渲染，并要求给项目和单品起名。这一轮做了：
- **抠图**：16 张用 `assets.py studio` 抠成透明图；吊灯另做一个截短吊线的版本。
- **替换**：旧渲染出现在全稿多页，整图用 `swap_cutout` 换，局部裁切用 `regions.py` 里的像素区域 + `K.set_region` 换。
- **改名**：项目改为「节序 Nodes in Order」，六件分别是围炉、东道、西宾、比肩、藏器、秉烛（取意见 `references/naming.md`）。
- **改文字**：不再符合新设计的文字逐条更新（`CN` 和 `EN.update`）。
- **多角度页**：每件单品渲染页后加一页（`K.build_views`）。
- **保留旧稿**：旧草图、旧场景暂时留在原位，在 `image-checklist-v25.md` 里标「旧稿」，并给出重新生成的提示词。

## 第三轮：待补图版（`build_fill_in.py` + `slots.py`）
用户要一份能直接把 AI 图放进去的 PPT：
- **数据**：`slots.py` 里写好每个缺图位置的提示词、比例、参考图，以及页面上的中英标签。
- **构建**：`build_fill_in.py` 在 I、J、K、L、M 页的最终位置用 `K.add_slot` 放占位框，在旧草图、旧场景上用 `K.add_old_card` 盖提示卡片。
- **页码表**：构建后扫描形状名，写出 `slot_pages.json`（编号 → 页码），用来生成清单末尾的页码表（见 `image-checklist-v26.md`）。
