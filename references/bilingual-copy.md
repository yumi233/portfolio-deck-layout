# 中英双语排法

**默认中英对照**：中文在上，英文跟在下面。用户的原稿往往只有中文正文，这时要补英文对照。用户明确说只要中文（或只要英文）时才不配。
原稿只有英文时，反过来补中文，中文仍然放在上面。

## 哪些要配英文
- **要配**：
  - 说明正文、导语 / 主张句、总结句
  - 单元标语（如「一柜一杆」→ One Pedestal, One Frame）
  - 过程页和主图页的说明、材料 / 规格 / 工具清单、图注
  - 扉页标语
- **默认不配**：表格单元格、地图和示意图上的标签、关键词行（如「买茶、择水」）、条目小标题、参考资料列表。这些页面本来就满，而且标签多是专有名词。
- 页面标题、章节名、单元名本来就是中英成对的（H2 / C / G 模板）。

## 怎么排
| 方式 | 何时用 | 写法（`K.add_en` 的 spec） |
|---|---|---|
| 段落成对 | 一般正文：先整段中文，再整段英文 | `('block', 'English text')`；多行清单用 `\n` 分行 |
| 逐句成对 | 案例页：每句中文下面紧跟它的英文 | `('pairs', ['en 1', 'en 2'])`，长度和中文段落数一一对应 |
| 同行 | 很短的引语，如「形态推敲  Form Study」 | `('inline', 'Form Study')` |

- **字号**：中文 14/13/12/11/10 → 英文 11/10/10/9/8.5。
- **颜色**：英文用正文灰（中文是辅助灰时，英文也用辅助灰）。
- **行距**：中文 1.55 倍，英文 1.42 倍；中文段与英文段之间空 4pt。
- **换行**：英文按栏宽自动换行。`K.avail_width` 会量出到右侧下一个元素的距离，最多 250–260pt；中文的手动换行保持不变。
- **测量**：英文行数用真实字体文件量出来（`configure(en_font_file=...)`），这样移动下方元素时位置算得准。

## 版面怎么让位
加了英文的文本框会变高，`K.apply_en` 随后调用 `K.reflow`：
- **列模式**（默认）：只把同一列、在它下方的元素往下推。互不相干的左右两栏各自保持不动。
- **行模式**（`rows=True`）：用于「编号 | 名称 | 说明」这种整行排列的列表，下方所有元素一起下移，行与行保持对齐。
- **事后对齐**：推完后用 `K.anchor` 重新对齐附属元素：
  - 编号对齐到名称
  - 时间轴圆点居中在主线上
  - 图注紧贴图片下方
- **重新居中**：最后 `K.vfit` 让内容块在内容区里重新垂直居中，再用 `K.content_bottom` 检查是否超出 y≈494。

## 页面放不下时的取舍顺序
1. **先缩短英文**（信达雅的短句，而不是逐字翻译）。用户明确偏好这一招，因为它能保住原来的版式。
   例：时间轴「《僮约》记买茶，《荈赋》写择水选器。茶事进入日常文献。」→ *Tea enters the written word.*
2. 收紧行间距（把原稿留下的大空框量成实际高度，用 `K.fit_height`）。
3. 局部重排：只调这一页的行高和块间距（如工艺路线页按每行实际高度重排）。
4. 最后才考虑换结构，比如把交错时间轴改成单排。**换结构前先问用户**，用户可能更喜欢原排版。

## 翻译风格
- **意译**：设计语言要准确、凝练、有画面感。不逐字对译，不堆砌形容词。
- **大小写**：标语用首字母大写 + 平行结构（*Folded Planes, Gathered Light*）；正文用句首大写；小标签用全大写。
- **专有名词**：书名可以意译（*Classic of Tea*）或音译（*Tong Yue*）；人名用拼音（*Lu Yu*）。
- **行业用词**：用该领域的通用英文，例如：
  - 空间：平面图 floor plan、动线 circulation
  - 品牌：标志 logo / mark、辅助图形 supporting graphics
  - UI：首页 home、组件 component
  - 服装：廓形 silhouette、面料 fabric
  - 茶家具：盖碗 gaiwan、茶席 tea setting
- **拿不准的术语**：列出来请用户确认。
- **请用户核对**：交付时说明哪些地方是意译，例如「调饮」译成 *taken with milk and sugar*。
- **单词孤行**：英文最后一行如果只剩一个词，改短这句，不要硬缩字号。
