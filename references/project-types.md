# 项目类型：怎么理解一份稿子、该有哪些页、缺哪些图

这套版式不只用于家具。不管内容是什么，都先回答三个问题：
1. **这是哪类项目？** 从下面八类里选最接近的一类；跨类的项目（例如「品牌 + 空间」）可以组合两类的页面和图。
2. **「单元」是什么？** 单元是作品里一个个可以单独展示的对象：一件产品、一个空间、一套物料、一个界面流程、一组插画、一个系列造型、一组照片、一个研究课题。单元决定单元标题页（G）和每单元的页面循环。
3. **用户手上有什么？** 先盘点已有的图、文字、源文件（3D 模型、AI/Figma 文件、相机原片），再决定缺什么、各从哪里补。

## 通用骨架（所有类型共用）

```
A 封面
B 目录
C 扉页 → 研究 / 背景章：D 信息图页、E 案例页
C 扉页 → 构思章：F 灵感来源页、D 定位 / 策略 / 方法页
C 扉页 → 成果章：每个单元循环 G → H → I → J → K；全组 L → M
C 扉页 → 总结章：D 总结页、D 参考资料页
A 封底
```
- **单元页面循环**（所有类型都按这个思路，具体放什么见下面各类型）：
  - **G 单元标题**：单元名大字居中，配一张预告图。
  - **H 过程**：怎么来的，例如草图、草稿、推敲、线框、试验。
  - **I 主图 / 说明**：主图 + 关键词 + 一段说明 + 材料或规格。
  - **I′ 多视角 / 技术说明**：其他角度、技术图、尺寸、规范。
  - **J 细节**：3 张特写 + 1 张结构或拆解图。
  - **K 情境**：用起来、放进去、穿上身、上墙、上线时的样子。
- **补图通用原则**：
  - 每个单元至少要有：**主图、过程、细节、情境**四类图。
  - 整组至少要有：**总览图**（全部单元放在一起）、**材质 / 色板 / 字体规范**（这个作品的「材料」）、**氛围大图**。
- **强调色**：从作品主色推导（见 layout-rules.md §5）。作品本身几乎无彩时用茶红。
- **调研部分**：图片默认转档案感灰度，重点用强调色标出。成果部分保留作品本色，不加强调色。

## 1 产品 / 家具
- **单元**：一件产品或家具；成套作品就是一个系列。
- **页序**：G 单品标题 → H 草图 / 形态推敲 → I 白底渲染 + 说明 → I′ 多角度、三视图 + 尺寸 → J 爆炸图 + 3 处节点 / 材质特写 → K 场景 ×2。全系列：L 系列总览 + 材质板 → M 大场景 ×2–3。
- **标准配图**：
  - 白底渲染（3/4 视角）：必需。
  - 正 / 侧 / 背面。
  - 三视图：从 3D 导出最准。
  - 爆炸图。
  - 节点 / 材质特写 ×3。
  - 场景 ×2：一竖一横。
  - 系列合影、材质板。
- **常见缺口**：三视图、爆炸图、场景、材质板。
- **图从哪来**：渲染软件、3D 导出、实物拍摄、AI（用渲染图作参考图）。
- **提示词镜头**：studio product photograph、orthographic drawing、exploded axonometric、macro close-up、editorial interior photograph。
- **完整例子**：`examples/nodes-bamboo-court/`（茶家具）。

## 2 室内 / 建筑 / 景观
- **单元**：一个空间（客厅、茶室、展厅）、一栋建筑、一处场地；大项目可以按「区域 / 楼层 / 节点」拆成多个单元。
- **页序**：D 场地 / 现状分析（区位、气候、人流，用灰度 + 强调色标重点）→ F 概念来源 → G 空间名 → H 草图 / 体块推敲 / 分析图 → I 主效果图 + 设计说明 → I′ 平面 / 立面 / 剖面图（尺寸、图例）→ J 材料节点、灯光、细部 ×3 + 轴测 / 爆炸 → K 不同时段或视角的效果图 ×2。全组：L 材料板 + 总平面 → M 鸟瞰 / 大场景。
- **标准配图**：
  - 主效果图（16:9 或 3:2）。
  - 平面、立面、剖面图：从 CAD、SU、Rhino 导出，线稿转透明。
  - 轴测分析。
  - 材料样板。
  - 细部特写。
  - 日景、夜景。
  - 人视、鸟瞰。
- **常见缺口**：轴测爆炸、材料板、夜景、细部。
- **提示词镜头**：architectural visualization、eye-level 24mm、aerial view、axonometric diagram、material board flat-lay、dusk lighting。
- **强调色**：常常来自木色、砖色、植物绿。效果图整体偏灰时，用茶红。

## 3 平面 / 品牌
- **单元**：一套品牌，或品牌里的一类触点（标志、包装、物料、导视）；多个品牌项目就是多个单元。
- **页序**：D 品牌背景 / 受众 / 竞品 → F 灵感与关键词（moodboard）→ G 品牌名 → H 草稿 / 标志推敲 / 字体试验 → I 标志主展示 + 理念说明 → I′ 规范页（字体、色板、网格、最小尺寸、错误用法）→ J 细节：工艺、纸张、烫印、特写 ×3 → K 应用样机：包装、名片、导视、海报、社媒。全组：L 全物料平铺 → M 品牌氛围大图。
- **标准配图**：
  - 标志：矢量、透明底。
  - 色板：可以由 kit 直接画色块。
  - 字体样张。
  - 物料平铺。
  - 样机 ×3–6。
  - 工艺特写。
- **常见缺口**：样机、工艺特写、氛围图。
- **图从哪来**：AI / Figma 导出、样机模板、AI 生成样机。
- **提示词镜头**：flat-lay mockup、packaging mockup、signage in situ、paper texture macro、brand moodboard。
- **强调色**：直接用品牌主色的沉稳版。品牌主色很艳时，只在分析页用一点。
- **注意**：品牌页面里，品牌本身的颜色要原样出现，不要去色。版式规则里的「黑白灰」只管版式本身的文字和线条。

## 4 UI / 交互
- **单元**：一个产品或 App 的一条核心流程（例如注册、下单、播放），或一个功能模块。
- **页序**：D 用户研究、旅程图、痛点（强调色标出关键点）→ F 竞品、灵感 → G 功能 / 流程名 → H 线框图、信息架构、用户流程图 → I 关键界面高保真（设备样机或平铺）+ 说明 → I′ 设计系统：组件、色板、字体、栅格 → J 交互细节：状态、动效分解、微交互 ×3 → K 使用情境：手持、桌面、真实环境。全组：L 全部界面平铺总览 → M 发布图 / 主视觉。
- **标准配图**：
  - 线框图。
  - 高保真截图：从 Figma 导出 @2x。
  - 设备样机。
  - 流程图。
  - 组件规范。
  - 交互状态序列。
  - 情境图。
- **常见缺口**：设备样机、情境图、动效分解。
- **提示词镜头**：device mockup on neutral surface、hand holding phone、clean UI flat lay；界面本身不要让 AI 画，用真实截图贴进样机。
- **强调色**：用产品的主品牌色。

## 5 插画 / 艺术
- **单元**：一幅作品、一个系列或一组角色。
- **页序**：F 创作来源（文本、参考、故事）→ G 作品 / 系列名 → H 草图、线稿、色稿 → I 作品主图（大图居中或出血）+ 创作说明 → I′ 系列排列 / 角色设定 / 三视图 → J 局部放大 ×3（笔触、纹理、细节）→ K 应用：展览现场、出版物、衍生品。全组：L 全部作品墙 → M 展览大场景。
- **标准配图**：
  - 原作高清扫描。
  - 过程稿 ×2–3。
  - 局部特写。
  - 展陈 / 出版样机。
- **常见缺口**：过程稿、展陈图、衍生品样机。
- **提示词**：只生成展陈、样机、氛围，**不要让 AI 改画或重画作品本身**。
- **强调色**：取作品主色调的沉稳版；作品是黑白的，用茶红。

## 6 服装 / 饰品
- **单元**：一个系列，或系列中的一套造型（look）、一件单品。
- **页序**：D 趋势 / 灵感调研 → F moodboard → G 系列名 / look 编号 → H 设计手稿、款式图 → I 成衣主图（模特或平铺）+ 说明 → I′ 正、背、侧款式图 + 工艺单 → J 面料、辅料、工艺特写 ×3 → K 上身 / 街拍 / 走秀情境。全组：L 系列阵列（lineup）+ 面料卡 → M 大片。
- **标准配图**：
  - 款式图：平面线稿，转透明。
  - 成衣平铺或棚拍。
  - 面料小样。
  - 工艺特写。
  - 上身图。
  - 系列 lineup。
- **常见缺口**：上身图、面料卡、lineup。
- **提示词镜头**：fashion editorial、full-length studio shot、fabric swatch macro、lineup on seamless background；人物的脸要不要出现，先问用户。
- **强调色**：取系列主色。

## 7 摄影
- **单元**：一组照片（一个系列、一个题材、一次拍摄）。
- **页序**：D 题材背景 → F 参考与动机 → G 系列名 → I 代表作大图（M 式单图）→ I′ 组照排列（2–4 张一页，错落排）→ J 局部 / 联系表（contact sheet）→ K 展览 / 出版样机。全组：L 全系列缩略墙。
- **标准配图**：原片（不改动）、联系表、展陈 / 画册样机。
- **常见缺口**：几乎不缺作品图，缺的是展陈样机和拍摄现场花絮。
- **注意**：作品照片**不要去背、不要转灰度、不要用 AI 修改**。版式只负责留白和排列。
- **强调色**：黑白摄影用茶红；彩色组照取主色调。

## 8 研究报告 / 课程汇报 / 毕业答辩
- **单元**：一个研究问题、一个章节或一个实验 / 方案。
- **页序**：
  - A 封面 → B 目录 → C 扉页（背景 / 方法 / 发现 / 方案 / 结论）。
  - D 信息图页为主：数据图、流程、框架、对比表；表格和图表照版式重新上色。
  - E 文献 / 案例页。
  - I 方案主图 + 说明。
  - J 实验或细节证据。
  - D 结论页、D 参考文献页。
- **标准配图**：图表（尽量用 PPT 原生图表重画）、方法流程图、现场 / 实验照片、方案图、对比图。
- **常见缺口**：方法示意图、概念图、各章扉页插图。
- **补图优先级**：先用线稿或图表补，AI 只补概念插图。
- **强调色**：取学校、课题或方案的主色；不确定时用茶红。图表里最多用强调色加两个灰。

## 跨类与拿不准时
- **跨类**：主类型定页序，次类型补页面。例如「品牌 + 空间」：按品牌走，但多出平面图和空间效果图（I′、K）。
- **拿不准**：先按通用骨架做，把判断写在给用户的「理解与计划」里，让用户确认，例如：「我把它当作 UI 项目，单元是三条核心流程。对吗？」
- **单元太多**（超过 8 个）：挑 3–5 个代表单元走完整循环，其余放进 L 总览页或 I′ 组合页，并在计划里说明。
- **一页放不下**：按 layout-rules.md 的取舍顺序处理；不要缩小正文字号。
