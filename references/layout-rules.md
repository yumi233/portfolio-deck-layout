# 版式系统：极简东方衬线

这一份写的是**视觉系统本身**：网格、字体、字号、颜色、线条、图片处理，**任何内容都通用**，不管是作品集、设计报告、课程汇报、研究报告还是提案。内容怎么组织、该有哪些图，见 project-types.md 和 page-templates.md。

本系统来自一份家具作品集参考稿（「厝桥 Shelter Bridge」，61 页）的像素实测，并在一次完整的重构实践中定稿。所有数值以 **pt** 为单位，页面为 **960 × 540 pt**（16:9，33.867 × 19.05 cm）。字号即 WPS / PowerPoint 的字号。

## 1. 风格要点

**大面积白底留白，中英双语衬线字，黑白灰为主，加一点从作品主色推导出的强调色。作品（图）是主角，文字只做注解。**

- 每页只有一个视觉焦点，文字面积一般不超过页面的 20%（研究报告类可以放宽到 35%，靠留白和层级保持安静）。
- 不用阴影、渐变、圆角卡片、色块底，也不给图片加描边。
- 作品展示部分不加强调色，颜色来自作品自身（材料、品牌色、画面）。
- 分析类页面（调研、数据、图解）可以用强调色标重点，但用量要少（不超过 5%）。

## 2. 页面与网格

| 项 | 值 |
|---|---|
| 页面 | 960 × 540 pt。原稿是其他 16:9 尺寸时整体等比缩放，例如 1200×675 → ×0.8 |
| 背景 | 纯白 `#FFFFFF`；只有目录页用 `#FAFAFA` |
| 页码 / Logo / 页眉 / 页脚 | **不用**；原稿里的都删掉 |
| 页面标题（H2） | 文字框左上角在 (33, 25)，文字顶端约在 y=27 |
| 右上角标（如「案例分享」） | 右边界 x=930，上边 y=25 |
| 内容区 | x 60–900，y 74–490；内容块在区内**垂直居中**，太高时顶对齐 |
| 图片出处 | 8pt 灰色，左下角 (33, 511)；调研类报告**保留**出处 |
| 分栏 | 左右二分最常见，中缝 40–60pt；文字栏宽 250–260pt |

参考线（cm）：竖向 1.16 / 2.12 / 16.93 / 31.75 / 32.8；横向 0.95 / 2.6 / 17.3。

## 3. 字体

| 角色 | 首选 | 本机没有时 |
|---|---|---|
| 中文（标题与正文） | 思源宋体 Source Han Serif SC（Light / Regular） | 方正书宋 → 宋体-简 Songti SC（macOS）→ 华文宋体 → SimSun |
| 英文（标题与正文） | EB Garamond / Adobe Garamond Pro | Garamond（Office / Windows 自带）→ Hoefler Text（macOS）→ Baskerville |
| 技术标注（只用于图纸） | Helvetica Neue / Inter / Arial | — |

- 用 `scripts/fonts.py` 检测本机可用的字体组合。
- 每个文字块都要分别写入 latin 和 ea 字体，否则中文会落到系统黑体。
- 同一组字体还要写进主题字体，这样用户以后新加的文字也一致。
- 交付时告诉用户实际用了哪组替代字体，以及换到别的系统上会被替换。
- 英文 Garamond 系字体默认用旧式数字（如 1391、P/01），这是想要的效果，不用改。

## 4. 字号层级

| 层级 | 用在哪 | 中文 | 英文 | 颜色 |
|---|---|---|---|---|
| H0 封面标题 | 项目名 | 28 | 24 | 标题黑 |
| H1 章节 / 单元标题 | 扉页、单元标题页 | 28 | 26–28 | 标题黑 |
| H2 页面标题 | 内容页左上角 | 14 | 12（与中文同一行，中间隔两个全角空格） | 中文标题黑，英文正文灰 |
| H3 案例标题 | 案例页文字栏 | — | 14，全大写，字距 +1 | 标题黑 |
| 导语 / 主张 | 一页的核心句 | 14 | 11 | 标题黑 |
| 条目标题 | 时间轴、列表的小标题 | 11 | — | 标题黑（靠颜色和位置区分，不加大） |
| 正文 | 说明文字 | 11–12 | 9–10 | 正文灰 |
| 标注 / 图注 | 图下标签、关键词行 | 9–10 | 8–8.5 | 辅助灰 |
| 出处 | 图片来源 | 8 | 8 | 辅助灰 |

- **行距**：中文 1.55–1.6 倍；英文 1.42 倍。
- **中英间距**：中文段与英文段之间留 4pt；成对句与下一组之间留 8pt。
- **对齐**：正文左对齐；标题页、扉页、案例文字栏居中。
- **字号下限**：不为塞内容而把正文缩到 11pt 以下；放不下就删字、拆页或改排版。

## 5. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 标题黑 | `#231815` | 标题、条目标题 |
| 正文灰 | `#3E3A39` | 正文、英文 |
| 辅助灰 | `#595757` | 标注、出处、英文副行 |
| 细线浅灰 | `#DCDCDA` | 分隔线、目录横线、表格行线 |
| 线描灰 | `#B5B5B6` | 示意图外框、圆 |
| 中灰 | `#7C7979` | 时间轴主线、表头下线、竖向引导线 |
| 强调色 | 从作品主色推导（无彩时为茶红 `#8C2C2C`） | 分析类页面的编号、圆点、引线、地图重点区、图表重点系列 |
| 强调色浅 | 同色系浅色（无彩时为 `#CBA7A9`） | 次要重点、地图次要区域 |
| 目录底 | `#FAFAFA` | 只用于目录页 |

**强调色怎么定**（每个项目都要做，并告诉用户）：
1. 选 3–6 张最能代表作品的主图（成果图，不用调研图），运行 `python -I scripts/assets.py accent 图1 图2 …`。
2. 脚本会忽略白色页面和背景，在有彩像素里找面积最大的色相，生成两个颜色：
   - 沉稳版：HLS 亮度 0.30、饱和度 0.45，并保证在白底上对比度 ≥ 4.5:1。
   - 浅色版：亮度 0.76、饱和度 0.28。
3. 作品几乎无彩（有彩像素不到 2%：黑白摄影、素描、纯金属、灰度效果图）时，脚本会退回茶红。
4. 品牌项目直接用品牌主色的沉稳版。用户指定了颜色时，以用户为准。
5. 构建时调用 `K.set_accent(main, light)`。交付说明里写一句：「强调色取自 ×× 的主色（色值），只用在分析类页面」。

**原稿配色怎么映射**：
1. 先按「文字 / 线 / 填充」区分颜色的用法。
2. 按明度归入上表。
3. 饱和色在分析章节变成强调色，在其他章节变成灰。

`pptx_kit.recolor` 已经实现了这套逻辑。注意：**作品本身的颜色**（品牌色、产品材质、画面）保持不动，只有版式元素（文字、线、色块、图表）参与映射。

**地图与图表**：底图用浅灰 `#E6E6E4`，边界用白线；重点区域用强调色及其浅色梯度；图表最多用「强调色 + 两个灰」。

## 6. 线条与装饰

- **发丝线**：0.5pt；目录横线长 100pt。
- **表格**：去掉所有填充；表头下线用中灰 0.5pt，行线用浅灰 0.5pt；表头文字用标题黑，不加粗。
- **时间轴**：中灰或强调色主线，圆点直径 4–6pt，圆点中心落在主线上。
- **三栏流程页**（来源 → 提炼 → 方案）：栏与栏之间用浅灰竖线隔开。
- **段落左侧竖线**（可选）：0.75pt，`#7C7979`，高度等于段落。
- **标注引线**：直线或折线，标签分两行（名称 + 灰色副行）。
- **不加**：标题下划线、色条、侧边色带、卡片底色。

## 7. 图片

1. **矩形直角**：不描边、不圆角、不加投影。
2. **有背景的单体图要抠成透明 PNG**：产品渲染、单件物料、样机这类「物体」图。白底用 `assets.py cutout`，灰底或渐变影棚用 `studio`。纯白页面上，近白或灰色的底会露出边框。
   **不抠图**的：空间效果图、插画、摄影作品、界面截图、情境图。这些直角放置，原样展示。
3. **情境 / 大图**有三种排法：
   - 双图错落：一张竖图约 328×492，一张约 330×414，两张上下边故意不对齐。
   - 一张出血 + 一张内缩。
   - 单图居中，宽度占页面的 60–87%。
4. **细节特写**：3 张等大横排，下方居中放「中文 10 / 英文 8」标签。
5. **单元标题页的预告图**：物体类用运动模糊的抠图（`assets.py blur`）；其他类用主图的局部或低饱和缩略图。不要和两页后的主图完全重复。
6. **调研拼贴 / 历史插图 / 参考图**：转成档案感灰度（`assets.py gray`）；灰底物件照片用 `knockout` 抠掉背景后转灰度。**作品本身不转灰度。**
7. **线稿**（目录页、扉页插图）：重新着色为中灰（`assets.py lineart`）。
8. **一张图在多页复用**时，同一组页面里不要连续出现两次一模一样的图。

## 8. 叙事结构（页序）

通用骨架如下；每种项目类型的「单元」和具体页序见 project-types.md。

```
A 封面
B 目录（只列章节：中文｜英文｜细线｜P/01）
每章：C 扉页
  研究 / 背景章：D 信息图页 / E 案例页
  构思章：F 灵感来源页 → D 定位 / 策略 / 方法
  成果章：每个单元 G 标题 → H 过程 → I 主图说明 → I′ 多视角 / 技术说明 → J 细节 → K 情境
          全组 L 总览 + 材料 / 色板 → M 大图
  总结章：总结页 → 参考资料页
A 封底（与封面相同）
```

缺哪类图：完整版里跳过对应页面；待补图版里留好位置；两者都写进《图片补全清单》（见 image-audit.md）。

## 9. 不做什么

- 不改动用户的内容观点，不编造数据。英文只译用户已有的中文。
- 不重画用户的矢量图（地图、示意图）：保留原图，只改色、改尺寸。
- 用户喜欢原来的某种版式时，**优先压缩文字**（例如改用短英文）来保留它，不要换结构。
- 不删除图片出处和演讲者备注。导航性质的文字（目录页码范围、扉页关键词）可以删，但要在交付说明里列出来。
