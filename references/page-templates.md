# 13 种页面模板（A–M）

模板按**作用**命名，不按内容命名。每种模板写明：何时用、怎么构成、`pptx_kit` 的函数，以及不同项目类型往里放什么（详见 project-types.md）。坐标单位为 pt，页面 960×540。

「单元」指作品里一个可以单独展示的对象：一件产品、一个空间、一套品牌物料、一条界面流程、一组插画、一个系列造型、一组照片、一个研究课题。

目录：A 封面/封底 · B 目录 · C 章节扉页 · D 信息图/内容页 · E 案例页 · F 灵感来源页 · G 单元标题页 · H 过程页 · I 主图说明页（含 I′ 多视角/技术说明）· J 细节页 · K 情境页 · L 总览页 · M 大图页 · 原稿页归类

---

## A 封面 / 封底
```
┌──────────────────────────────────────────────┐
│   项目名 28            ┌──────────────────┐   │
│  Project Name 24       │  封面主图          │   │
│   主题 12 / Topic 10   │  约 472×310        │   │
│                        └──────────────────┘   │
│  October 2026 (68,462)                       │
└──────────────────────────────────────────────┘
```
- **文字栏**：x 40–320，文字居中。项目名中文 28 / 英文 24；主题中文 12 / 英文 10；日期 12pt，位于 (68, 462)，用英文月份写法。
- **右侧主图**：放进 (440, 150, 472×310)。各类型放什么：
  - 产品：一组抠图合影，用 `assets.py compose` 拼。
  - 空间：一张效果图，直角，不加框。
  - 品牌：物料平铺或标志。
  - UI：设备样机组。
  - 插画、摄影：代表作。
  - 研究：一张概念图或线稿。
- **函数**：`K.build_cover(...)`。封底用同一个函数再生成一页。

## B 目录
- **背景**：`#FAFAFA`。
- **行**：每行依次是「中文 14 ｜ 英文 12 ｜ 100pt 细线 ｜ P/01 8pt」，行距 40，整块垂直居中，所有行共用同一列英文。
- **右侧**：一张灰色线稿或黑白意象图，从项目里挑最有代表性的线稿、草图或局部。
- **只列章节**：删掉的导航文字，在交付说明里列出来。
- **函数**：`K.build_toc(slide, rows, art_png)`。

## C 章节扉页
- **构成**：中文 28 / 英文 26 居中，放在页面上部 1/3；可以加一行标语（中文 12 / 英文 10）；下方 y 260–440 放一张插图。
- **插图来源**（按优先级）：
  1. 该章已有的线稿、草图、分析图；
  2. 去背景并转灰度的参考物；
  3. 单元抠图排成一行；
  4. 一张低饱和的局部。
- **不放**章节号、关键词列表，也不放大面积彩图。
- **函数**：`K.build_divider(...)`。

## D 信息图 / 内容页（最常用）
- **用途**：调研、分析、数据、流程、对比表、方法、结论、参考文献。
- **页面标题**：左上角 `K.header(slide, 中文, 英文)`。
- **内容**：放在内容区，用 `K.vfit` 垂直居中。
- **配色**：调研图片转灰度，重点用强调色标出。
- **表格**：用 `K.restyle_tables` 去掉底色。
- **图表**：优先用 PPT 原生图表，配色只用强调色和两个灰。
- **出处**：`K.credit(...)`。

## E 案例页
- **用途**：介绍别人的作品、竞品、参考项目、文献里的案例。
- **构成**：
  - 右上角 `K.corner_label(slide, '案例分享')`，这类页不放左上角的页面标题。
  - 左侧：主图 400×225，下面 3 张小图，用 `K.set_crop_aspect` 统一比例。
  - 右侧文字栏 x 540–880，居中：英文全大写标题 14 → 作者｜项目名 12 → 关键词 12 + 英文 10 → 若干句「中文 11 / 英文 9」，逐句对应。
- **多个案例 + 对比表**：用 D。

## F 灵感来源页
- **用途**：来源 → 提炼 → 方案。来源可以是古画、自然物、建筑、文本、用户洞察、品牌故事。
- **构成**：三栏，用浅灰竖线 `K.line` 隔开；中栏是 2–3 个提炼出的特征（小标题 + 中英各一句），右栏是对应的方案小图。

## G 单元标题页
- **用途**：每个单元的开场页。
- **构成**：英文名 28 居中，放在 (180, 76, 600)；中文全称 12 辅助灰放在下面；预告图居中，放在 (160, 150, 640, 330)。
- **预告图**：
  - 产品类：抠图加运动模糊（`assets.py blur`）。
  - 空间、品牌、UI：主图的局部或低饱和缩略图。
  - 插画、摄影：作品的一角。
  - 原则：不要和两页后的主图完全一样。
- **函数**：`K.build_g(...)`。

## H 过程页
- **用途**：作品是怎么来的。产品是草图、形态推敲；空间是体块和分析；品牌是标志推敲和字体试验；UI 是线框图和信息架构；插画是线稿和色稿；服装是手稿和款式图；研究是方法流程。
- **构成**：
  - 页面标题写单元名（中英）。
  - 过程图放在 (56, 92, 552, 368)。
  - 右侧文字块 x=650、宽 260、垂直中心在 y=276：引语「过程 Process」10pt（或「形态推敲 Form Study」「线框 Wireframe」，按类型换），接着标语中文 14 + 英文 11，再接说明中文 12 + 英文 10，用 `K.text_block(..., [0, 8, 16])` 叠放。
  - 原稿文本框是右对齐的，叠放前先 `K.left_align`。

## I 主图说明页
- **构成**：主图放在 (64, 92, 496, 384)；右侧文字块 x=640、垂直中心在 y=284，从上到下是关键词或标语（14+11）、说明（12+10）、材料 / 规格 / 工具清单（10+8.5，多行）。
- **主图来源**：
  - 产品：白底渲染抠图。
  - 空间：效果图。
  - 品牌：标志或主物料。
  - UI：关键界面或设备样机。
  - 插画、摄影：作品本身，不抠图、不调色。
  - 服装：成衣图。
- **I′ 多视角**（同一单元的其他角度、其他界面、其他画面）：2–3 张等高、底边对齐、水平居中，间距 48pt；每张下方标签「中文 10 / 英文 8」，例如「正面 Front」「首页 Home」「局部 Detail」。函数：`K.build_views(...)`。
- **I′ 技术说明**：
  - 左 40%：主图。
  - 右 50%：技术图（三视图、平立剖、规范页、款式图、组件表），上方小标题，下方尺寸或参数行，用户要填的写成空格（`L ___ × W ___ × H ___ mm`）。

## J 细节页
- **构成**：左边一张大的结构 / 拆解图，放在 (56, 84, 304×380)，下方标签；右边 3 张等大特写 154×154，下方标签「中文 10 / 英文 8」，上方小标题。
- **各类型放什么**：
  - 产品：爆炸图 + 节点 / 材质。
  - 空间：轴测爆炸 + 材料节点、灯光。
  - 品牌：规范拆解 + 工艺、纸张。
  - UI：状态序列 + 微交互。
  - 插画：线稿叠层 + 笔触局部。
  - 服装：结构拆片 + 面料、工艺。
  - 研究：实验装置 + 证据照片。

## K 情境页
- **用途**：作品在真实环境里的样子。产品是使用场景；空间是不同时段或视角；品牌是样机和现场；UI 是手持或桌面；插画是展陈、出版；服装是上身；摄影是展览。
- **构成**：纯图，不放文字。双图错落：竖图 (135, 30, 320×480)，第二张 (495, 98, 330×412)；也可以一张出血 + 一张内缩。

## L 总览页
- **构成**：左半放一张全组总览图（产品组合、总平面、物料平铺、界面墙、作品墙、系列 lineup）；右半放材料 / 色板 / 字体清单，每项「编号 + 中文名 + 英文名 + 用在哪」。
- **只有总览、没有材料图时**：先排总览，材料图写进补图清单。

## M 大图页
- **构成**：单张大图居中，宽度占页面的 60–87%，不放文字。
- **需要命名时**：用 G 的版式，英文名在上、图在下。
- **数量**：全组一般 2–3 张，在时间、空间或情绪上拉开差异。

## 原稿页归类
| 原稿特征 | 归到 |
|---|---|
| 大标题 + 编号 + 关键词，几乎没有正文 | C |
| 多图 + 时间轴 / 地图 / 表格 / 图表 / 示意图 | D |
| 别人的作品照片 + 简介 | E（两个以上案例加对比表时用 D） |
| 原型 / 来源 → 特征 → 方案 | F |
| 草图、草稿、线框、推敲 + 一段说明 | H |
| 单张主图 + 关键词 + 材料 / 规格 | I |
| 多个角度 / 多个界面 / 技术图 | I′ |
| 材料、工艺、节点、局部特写 | J |
| 作品放在真实环境里的图 | K（单元）或 M（全组） |
| 全部单元的小图排列 | L |
| 平面布置、流程、用户旅程 | D |
| 总结、参考资料 | D |
